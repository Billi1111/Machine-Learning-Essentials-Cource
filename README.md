Update the path to haarcascade_frontalface_alt.xml in both files.

Update the dataset path in both faces_detection.py and face_Detection_2.py.

Run faces_detection.py to start capturing images for the first person.

The more images you collect, the better the accuracy.

Press Q to stop.

Repeat this process for each additional person.

After collecting all datasets, run face_Detection_2.py.

The camera will open, detect the trained faces, draw a square around them, and show their names.
